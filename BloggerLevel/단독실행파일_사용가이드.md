# 네이버 블로거 순위 조회 프로그램 - 단독 실행파일 사용 가이드

## 📁 파일 위치
실행파일: `dist/bloggerLevel_Main.exe` (43MB)

## 🚀 실행 방법
1. `bloggerLevel_Main.exe` 파일을 더블클릭하여 실행
2. GUI 창이 열리면 키워드를 입력하고 '실행' 버튼 클릭

## ⚙️ 환경 설정
프로그램을 사용하기 위해서는 네이버 API 키가 필요합니다:

### 방법 1: .env 파일 사용 (권장)
프로그램과 같은 폴더에 `.env` 파일을 생성하고 다음 내용을 입력:
```
NAVER_CLIENT_ID=your_client_id_here
NAVER_CLIENT_SECRET=your_client_secret_here
```

### 방법 2: 환경 변수 설정
시스템 환경 변수에 다음 변수를 추가:
- `NAVER_CLIENT_ID`: 네이버 API 클라이언트 ID
- `NAVER_CLIENT_SECRET`: 네이버 API 클라이언트 시크릿

## 📊 결과 파일
- 결과는 `result/bloggerlevel.xlsx` 파일에 저장됩니다
- '결과 폴더 열기' 버튼으로 결과 폴더를 바로 열 수 있습니다

## 🔧 주요 기능
- 키워드 기반 블로거 순위 조회
- 상위 5개 블로거 정보 수집 (블로거명, 오늘 조회수, 예상 일일 조회수)
- 엑셀 파일로 결과 자동 저장
- 여러 키워드 동시 처리 (컴마로 구분)

## ⚠️ 주의사항
- 네이버 API 키가 없으면 프로그램이 정상 작동하지 않습니다
- 인터넷 연결이 필요합니다
- 프로그램 실행 중 다른 작업을 할 수 있습니다 (백그라운드 처리)

## 🛠️ 빌드 정보
- PyInstaller v6.18.0으로 빌드
- Python 3.13.9 환경
- Windows 11 64bit용 실행파일
- GUI 애플리케이션 (콘솔 창 숨김)

## 📞 기술 지원
문제가 발생하면 다음을 확인하세요:
1. 네이버 API 키가 올바르게 설정되었는지
2. 인터넷 연결 상태
3. result 폴더에 쓰기 권한이 있는지
