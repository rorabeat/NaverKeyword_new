# 네이버 뉴스 크롤러 - EXE 버전

## 📦 개요

네이버 뉴스 크롤러의 독립 실행 파일 버전입니다.
Python 설치 없이 Windows 컴퓨터에서 바로 실행할 수 있습니다.

## 📋 시스템 요구사항

- **운영체제**: Windows 7 이상 (64비트 권장)
- **메모리**: 최소 2GB RAM
- **저장공간**: 500MB 이상 여유 공간
- **인터넷**: 네이버 뉴스 접근 가능한 인터넷 연결

## 📁 포함 파일

```
네이버 뉴스 크롤러/
├── NaverNewsCrawler.exe     # 메인 실행 파일 ⭐⭐⭐
├── start_crawler.bat        # 간단 실행 배치 파일
├── install_and_run.bat      # 설치 및 실행 배치 파일
├── EXE_README.md           # 이 파일
└── [추가 파일들...]
```

## ⚡ 빠른 시작 (3초만에 실행!)

### 🚀 **가장 간단한 방법**
1. `NaverNewsCrawler.exe` 더블클릭!
2. 브라우저 설치 팝업에서 **"예"** 클릭!
3. 끝! 🎉

---

## 🚀 설치 및 실행 방법 (상세)

### 방법 1: EXE 파일 직접 실행 ⭐⭐⭐
1. `NaverNewsCrawler.exe`를 **더블클릭**하여 실행
2. 브라우저 설치 확인 창이 나타나면 **예**를 클릭
3. 자동으로 Playwright 브라우저가 설치됩니다
4. 크롤러 GUI가 실행됩니다

### 방법 2: 간단 실행 배치 파일
1. `start_crawler.bat` 더블클릭
2. 자동으로 크롤러 실행

### 방법 3: 자동 설치 배치 파일
1. `install_and_run.bat` 파일을 **관리자 권한으로 실행**
2. 자동으로 필요한 프로그램들이 설치됩니다
3. 크롤러 GUI가 자동으로 실행됩니다

### 방법 4: 수동 설치
1. Python 3.7 이상 설치
2. 명령 프롬프트에서 다음 명령어 실행:
   ```cmd
   pip install playwright PyQt5 beautifulsoup4
   playwright install chromium
   ```
3. `NaverNewsCrawler.exe` 실행

## 💡 사용법

### 기본 사용
1. **키워드 입력**: 검색할 뉴스 키워드 입력
2. **개수 선택**: 수집할 기사 개수 선택 (1-100개)
3. **크롤링 시작**: 버튼 클릭하여 크롤링 시작
4. **진행상황 확인**: 실시간 진행률과 로그 확인
5. **결과 확인**: 완료 후 "결과 폴더 열기" 버튼으로 결과 확인

### 결과 파일 구조
```
results/
└── [키워드]/
    ├── 기사제목1_20260208.txt
    ├── 기사제목2_20260208.txt
    └── summary_[키워드]_시간.txt
```

## ⚠️ 주의사항

### 설치 시 주의
- **관리자 권한**으로 배치 파일 실행 권장
- **안티바이러스** 프로그램이 차단할 수 있음 (허용해주세요)
- **방화벽**이 인터넷 접근을 허용해야 함

### 사용 시 주의
- **과도한 크롤링**은 네이버 정책 위반 가능성
- **네트워크 오류** 시 재시도 해보세요
- **크롤링 중** GUI 응답이 느릴 수 있습니다

### 문제 해결
- **실행되지 않음**: Python 및 pip 설치 확인
- **브라우저 오류**: `playwright install chromium` 재실행
- **크롤링 실패**: 키워드나 네트워크 연결 확인
