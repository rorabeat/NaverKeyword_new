# 네이버 뉴스 크롤러 GUI 버전

## 개요

네이버 뉴스 크롤러의 그래픽 사용자 인터페이스(GUI) 버전입니다.
키워드와 크롤링 개수를 입력받아 자동으로 뉴스 기사를 수집하고 텍스트 파일로 저장합니다.

## 파일 구조

```
NaverNews/
├── navernews.py          # 메인 크롤러 모듈 (CLI 버전)
├── navernews_gui.py      # GUI 인터페이스 모듈
├── navernews_backup.py   # 백업 파일
├── results/             # 결과 저장 폴더
│   └── [키워드]/        # 키워드별 폴더
│       ├── 기사1.txt    # 개별 기사 파일
│       ├── 기사2.txt    # 개별 기사 파일
│       └── summary_키워드_시간.txt  # 요약 파일
└── README_GUI.md        # 이 파일
```

## 기능

### GUI 기능
- **키워드 입력**: 크롤링할 뉴스 키워드 입력
- **개수 설정**: 수집할 기사 개수 설정 (1-100개)
- **진행상황 표시**: 실시간 진행률 바
- **로그 표시**: 상세한 크롤링 로그 확인
- **결과 폴더 열기**: 크롤링 완료 후 결과 폴더 자동 열기

### 크롤러 기능
- 모바일 네이버 뉴스 검색
- 기사 제목, 본문, 작성일자 추출
- 중복 제거 및 스크롤 다운으로 추가 로딩
- 키워드별 폴더 자동 생성
- 개별 기사 파일 저장

## 사용법

### GUI 실행

```bash
cd NaverNews
python navernews_gui.py
```

### 인터페이스 설명

1. **크롤링 설정 그룹**
   - 키워드: 검색할 뉴스 키워드 입력
   - 수집 개수: 1-100개 사이의 숫자 선택

2. **버튼들**
   - 크롤링 시작: 크롤링 작업 시작
   - 중지: 진행 중인 크롤링 중단
   - 결과 폴더 열기: 크롤링 완료 후 결과 폴더 열기

3. **진행상황**
   - 진행률 바: 작업 진행률 표시
   - 상태바: 현재 상태 메시지

4. **로그 영역**
   - 실시간 로그 표시
   - 로그 지우기 버튼

## 출력 파일 형식

### 개별 기사 파일 (예: `기사제목_20260208.txt`)
```
제목: 부산시-해군, 해양·국방 인공지능 전환(AX) 공동 추진
작성일자: 2026.02.08
URL: https://n.news.naver.com/article/022/0004104131?sid=102
키워드: 인공지능
==================================================

[기사 본문 내용...]
```

### 요약 파일 (예: `summary_인공지능_20260208_143052.txt`)
```
키워드: 인공지능
요청 개수: 5
수집 개수: 5
검색 URL: https://m.search.naver.com/search.naver?ssc=tab.m_news.all&where=m_news&sm=mtb_jum&query=인공지능

수집된 기사 목록:
================================================================================
 1제목: 기사 제목 1
작성일자: 2026.02.08
URL: https://n.news.naver.com/article/...
--------------------------------------------------
 2제목: 기사 제목 2
...
```

## CLI 버전 사용법

GUI 없이 명령줄에서 사용하려면:

```bash
# 기본 모드 (사용자 입력)
python navernews.py

# 데모 모드
python navernews.py --demo

# 명령줄 인수로 실행
python navernews.py "키워드" 10

# 테스트 모드
python navernews.py --test
```

## 시스템 요구사항

- Python 3.7+
- PyQt5
- Playwright
- BeautifulSoup4
- Chrome/Chromium 브라우저

## 설치

```bash
pip install PyQt5 playwright beautifulsoup4
playwright install chromium
```

## 주의사항

- 크롤링 중에는 GUI가 응답하지 않을 수 있습니다
- 과도한 크롤링은 네이버 정책 위반이 될 수 있습니다
- 크롤링 속도는 네트워크 상황에 따라 달라집니다
- 결과 폴더는 `results/[키워드]/`에 생성됩니다

## 오류 해결

### PyQt5 import 오류
```bash
pip install PyQt5
```

### Playwright 브라우저 오류
```bash
playwright install chromium
```

### 크롤링 실패
- 키워드가 너무 길거나 특수문자가 많은 경우
- 네트워크 연결 상태 확인
- 네이버 정책 변경 가능성
